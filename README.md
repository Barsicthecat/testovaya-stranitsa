# Тестовая страница

Одностраничное веб-приложение «Проекты» — список проектов с поиском,
созданием, редактированием и удалением. Всё работает без сервера:
данные хранятся в `localStorage` браузера и переживают перезагрузку страницы.

**Живая страница (GitHub Pages):** https://barsicthecat.github.io/testovaya-stranitsa/

## Возможности

- 📋 Список проектов: эмодзи-иконка, название, описание, категория, статус, прогресс
- 🔍 Живой поиск по названию и описанию с подсветкой совпадений
- ➕ Создание проекта через модальную форму (валидация названия, дубликаты запрещены)
- ✏️ Редактирование и 🗑 удаление (с подтверждением)
- 💾 Автосохранение в `localStorage` — данные не теряются при обновлении страницы
- 📊 Живая статистика: всего / в работе / завершено
- ↺ Кнопка сброса к исходным 10 демо-проектам
- 📱 Mobile-first вёрстка, тач-цели ≥ 44px, безопасные отступы (notch)
- 🌙 Автоматическая светлая/тёмная тема по системным настройкам

## Технологии

Чистые HTML + CSS + JavaScript, **ноль зависимостей**. Работает из файла,
с любого статик-сервера и на GitHub Pages.

| Файл | Назначение |
|---|---|
| `index.html` | разметка |
| `styles.css` | стили (mobile-first, светлая/тёмная тема) |
| `app.js` | логика: CRUD, поиск, хранение |
| `DEVELOPMENT.md` | журнал ошибок разработки и их исправлений |

## Демо-данные

10 полностью вымышленных проектов (дачно-технологичная тематика):
«Северный Ветер», «Тихая Гавань», «КрапИва», «Дедов Скворечник 2.0»,
«Печкин Телеграф», «Огород на Подоконнике», «Скамейка у Пруда»,
«Бабушкин Архив», «Комариный Радар», «Войлок и Лоза».

## Тестирование

Страница проверена на виртуальном мобильном устройстве (Android-эмулятор,
Pixel 6 / Android 14, Chrome) — как на стандартной ширине (411dp), так и на
экстремально узком экране 320 CSS-пикселей: перекрытий элементов нет.
Полный журнал верификации и всех допущенных/исправленных ошибок:
**[DEVELOPMENT.md](DEVELOPMENT.md)**.
